# Score numeral artwork

These PNG glyphs are rasterized from **Nothing Font (5x7)** by **CTFonts**:
https://fontstruct.com/fontstructions/show/2095104/nothing-font-5x7

The font's FontStruct Commercial Software EULA prohibits webfont use and
redistribution of the font software. The application therefore ships only
rasterized representations of the digits and decimal point, as permitted by
the embedding clause. Do not add the original TTF or a converted webfont to
this repository.
